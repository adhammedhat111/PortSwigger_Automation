# PortSwigger_Automation

Automated Python scripts to solve Cross-Site Scripting (XSS) labs on PortSwigger Web Security Academy.

💡 Features
1- Automatically detects and solves XSS labs

2- Works with both reflected and stored XSS challenges

3- Lightweight and easy to use


⚙️ Tech Stack

Python 3
requests
bs4 (BeautifulSoup)
webbrowser

🚀 Usage
```
git clone https://github.com/yourusername/xssploit.git
cd xssploit
python3 lab_name
```
